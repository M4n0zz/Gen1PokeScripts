
**Simple MapBuilder**

A simple but powerful script that lets you temporarily customize your current map!

# ![preview](builder.PNG)

- Pressing button B places a tile block infront of the player.
- Use select button to choose between different tile blocks.
- The script resides in stack region and runs with the initial execution.
- It uses Map Script hijack to always run in the backround until map changes.
- A trainer battle will probably crash the game.

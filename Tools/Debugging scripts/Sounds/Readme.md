Sound Tester

A simple script to help you debug every game sound



- Select desired sound bank
	- 1 = bank 2
	- 2 = bank 4
	- 3 = bank 8
	- 4 = bank 1f

- Next selector adds the selected amound to the current playing sound ID. Use 00 you repeat playing the sound.

```
cd 0f 19 3e 04 4f ea 97 cf cd  
57 2d a7 c0 21 96 cf cb 56 3e  
1f 20 06 3e 01 17 35 20 fc e0  
f0 af ea 97 cf cd 57 2d a7 c0  
cd 0e 20 f0 f0 ea ef c0 fa 96  
cf 47 11 fd d8 1a 80 12 cd b1  
23 01 03 c1 21 00 c4 cd 5f 3c  
18 d7 00
```

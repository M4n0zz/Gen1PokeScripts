
**PokeDuplicator**

A minimal script that duplicates the first pokemon of your party to the second slot.


**Instructions**
- Put the pokemon to be duplicated in 1st slot
- Put a spare pokemon in the 2nd slot
- Run the script


**Warning**
Trainer battle data is typically reused by the game.

To work around this limitation, you can use **MultiScript installer** instead.

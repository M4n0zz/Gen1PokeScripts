
## PokeDuplicator

A minimal script that duplicates the first pokemon of your party to the second slot.


**Instructions**
- Put the pokemon to be duplicated in 1st slot
- Put a spare pokemon in the 2nd slot
- Run the script


**Warning**

The script is temporarily stored in trainer battle data, which is overwritten when a trainer battle begins.
